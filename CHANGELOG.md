# Changelog

## 1.0.0 - 2026-09-18

- Initial Orchestrix Forms platform foundation.
- Versioned form schemas, field registry, visual builder, server renderer, REST API, entries, rules, calculations, validation, workflows, jobs, payment/workflow state models, surveys, quizzes, security primitives, Gutenberg block, WP-CLI, migrations, and release tooling.

  secret-field storage, queue lease recovery, malformed REST request handling, and
  regular-expression safety checks.
- Added fail-fast verification, PSR-12, PHPUnit security/domain coverage, and expanded
  clean-WordPress regression smoke testing.
