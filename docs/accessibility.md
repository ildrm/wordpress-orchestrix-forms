# Accessibility

Generated controls use labels, fieldsets/legends for grouped choices, descriptions via
`aria-describedby`, required semantics, a focusable error summary, field-associated
errors, live status announcements, visible focus, 44px targets, forced-color support,
RTL-safe logical properties, and reduced-motion behavior. The builder provides button
alternatives to drag-and-drop and retains native keyboard focus order.

Automated browser accessibility testing and manual screen-reader/keyboard verification
have not been completed. WCAG 2.2 AA is the design target, not a certified claim.
